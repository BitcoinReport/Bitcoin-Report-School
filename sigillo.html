Sigillo

Crittografia OpenPGP per tutti — senza terminali, senza configurazioni.

Sigillo è un’applicazione desktop open source che rende la crittografia OpenPGP accessibile a chiunque. Notepad integrato, rubrica dei contatti, cifratura di testo, immagini, GIF animate, video, PDF, documenti e qualsiasi altro file — il tutto senza mai aprire un terminale. Supporta più identità, l’import di chiavi esistenti e l’aggiunta dei contatti da fingerprint o da file. Distribuita sotto licenza GPLv3.

// novità · v0.7.1

Cosa c’è di nuovo

👥
Aggiungi un contatto in tre modi
In Rubrica, Aggiungi contatto offre tre modi, tutti con la stessa schermata di conferma prima di salvare. Da fingerprint: incolli i 40 caratteri, in qualunque formato, e Sigillo scarica la chiave da keys.openpgp.org (comodo se la persona l’ha pubblicata su un keyserver). Da file: scegli un file .asc o lo trascini sulla Rubrica (solo desktop), anche se contiene più chiavi. Incollando il testo della chiave, come prima ma con la conferma.
🔍
Chiavi controllate prima di fidarti
La chiave scaricata deve avere esattamente il fingerprint richiesto, altrimenti viene scartata: il server non è una fonte attendibile, e i Key ID corti sono rifiutati. La conferma mostra il fingerprint a blocchi e le 15 parole, da verificare con la persona. Avviso se la chiave è scaduta o revocata; se è privata non si importa nulla. Nessun duplicato, e un avviso se un nome uguale ha un fingerprint diverso. Con Tor attivo la ricerca passa solo da Tor; senza Tor, la prima volta l’app avvisa che contatta un server pubblico.
📎
Allegati di qualsiasi tipo
Cifra e condividi PDF, documenti Word, Excel e PowerPoint, file LibreOffice, .txt, .csv, archivi .zip, audio e qualsiasi altro file. Chi li riceve li ritrova con il nome originale e li salva o li apre con un clic. Puoi allegare un file anche insieme a un messaggio di testo.
🛡
File grandi, nessuna traccia
I file vengono cifrati e decifrati a pezzi, senza caricarli tutti in memoria. Quello decifrato resta in una cartella riservata dell’app e viene cancellato quando lasci la schermata, alla chiusura e all’avvio successivo. Se un file è un programma (.exe, .sh, .apk…) Sigillo ti avvisa prima di aprirlo.
▶
Supporto multimediale
Cifra e decifra testo, immagini (JPEG, PNG, HEIC), GIF animate e video .mov e .mp4.
⚲
Multi-account
Gestisci più identità e coppie di chiavi simultaneamente. Passa da un account all’altro senza uscire dall’app.
🔑
Import chiave esterna
Importa una chiave privata OpenPGP già esistente — da GPG Suite, Kleopatra o riga di comando. Porti la tua identità senza doverla ricreare.
⏳
Time-lock Sperimentale
Blocco soft basato sul numero di blocco Bitcoin. Non è una garanzia crittografica — è un vincolo applicativo attivabile nelle impostazioni avanzate.

✓ v0.7.1 — La chiave pubblica mostrata da Sigillo è ora sempre identica a ogni avvio e su ogni dispositivo, a parità di seed phrase: il fingerprint non cambia e i contatti non devono rifare nessuna verifica. Dalla v0.7.0 puoi anche aggiungere i contatti da fingerprint o da file .asc. I messaggi cifrati e le rubriche delle versioni precedenti funzionano come prima.

✓ v0.6.0 — Allegati di qualsiasi tipo, nomi dei file ricevuti sempre controllati prima dell’uso, file decifrati cancellati dopo l’uso e aggiornate alcune librerie di rete per correggere problemi di sicurezza segnalati di recente. I messaggi cifrati con le versioni precedenti si decifrano come prima.

✓ v0.5.1 — Correzione di sicurezza: un messaggio ricevuto non può più avviare richieste di rete alla sola apertura. Rafforzati inoltre la Content Security Policy e la protezione della passphrase locale.

✓ v0.5.0 — Migliorata la stabilità su alcune configurazioni Linux durante la visualizzazione di contenuti multimediali decifrati.

// Come verificare la firma
▶ macOS / Linux 
# 1. Importa la chiave pubblica
gpg --import SIGNING-KEY.asc

# 2. Verifica la firma (sostituisci con il file scaricato)
gpg --verify Sigillo-macOS.dmg.asc Sigillo-macOS.dmg

# Output atteso:
# Good signature from "Mike - Bitcoin Report Italia"
# Primary key fingerprint: 1382 C05E 9772 233C C957  CA7A FF68 AF59 F8CE C835
▶ Windows (Kleopatra / Gpg4win) 
1. Scarica e installa Gpg4win da https://gpg4win.org
2. Apri Kleopatra → File → Importa → seleziona SIGNING-KEY.asc
3. Clic destro su Sigillo-Windows.msi → "Verifica firma" → seleziona il file .asc
4. Risultato atteso: "Firma valida di Mike - Bitcoin Report Italia"
Chiave di firma inclusa nella release: Scarica SIGNING-KEY.asc
